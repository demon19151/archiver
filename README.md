# Архиватор

Веб-приложение для сжатия и восстановления файлов без потери данных. Поддерживает одиночную и пакетную обработку, выбор файлов, статистику, скачивание архивов и восстановленных файлов.

## Архитектура

Пользовательский сайт обрабатывает файлы локально в браузере в отдельном Web Worker. Исходные данные не отправляются на сервер, поэтому сайт может работать с большими файлами.

Серверный API работает отдельно и используется песочницей преподавателя. Он запускает тот же кодек и принимает один файл одним HTTP-запросом.

## Методы архивирования

- **LZSS + Huffman** — поиск повторяющихся фрагментов и компактное кодирование.
- **LZ-токены + Huffman** — отдельные коды для байтов, длин совпадений и расстояний; для подходящих файлов до 2 МиБ проверяется окно до 256 КиБ.
- **LZSS без Huffman** — дополнительный вариант для коротких файлов без расходов на таблицу кодов.
- **RLE и смешанный RLE** — сжатие серий одинаковых байтов, в том числе рядом со случайными участками.
- **Repeat** — запись периодически повторяющихся блоков.
- **Delta и byte-shuffle** — преобразования для числовых данных, бинарных записей и PCM-аудио.
- **BWT + MTF + Huffman** — блочное контекстное сжатие текста, таблиц и бинарных данных. Числовые данные дополнительно проверяются с обратимыми разностями 16-/32-битных значений первого и второго порядка.
- **Store** — безопасное сохранение исходных данных, когда сжатие невыгодно.

Для каждого файла автоматически выбирается самый короткий корректный вариант.

Таблицы Хаффмана дополнительно уплотняются, когда это выгодно. Новая версия распаковывает прежние архивы; для чтения архивов с новыми методами требуется обновить сайт или сервер.

Контекстные методы сравниваются по полному размеру архива с прежними кандидатами, включая заголовок и контрольную сумму. Кодек выбирает между блоками 128 и 512 КиБ и применяет метод к файлам до 2 МиБ. Дополнительное сжатие требует больше процессорного времени. Режим хранения сохраняется для данных, которые уменьшить не удалось; гарантировать уменьшение любого файла невозможно.

## Структура проекта

- `src/codec.js` — общий кодек сжатия и распаковки.
- `src/server.js` — локальный HTTP-сервер и статические файлы.
- `src/browser/` — браузерная адаптация кодека и Web Worker.
- `public/` — пользовательский интерфейс.
- `test/` — тесты кодека и браузерного Worker.
- `scripts/` — сборка браузерного Worker и benchmark.

## Запуск

Требуется Node.js 18 или новее.

Установить зависимости:

```bash
npm ci
```

Запустить локальный сайт и API:

```bash
npm start
```

Открыть сайт:

```text
http://localhost:3000
```

Собрать браузерный Worker:

```bash
npm run build
```

Запустить тесты:

```bash
npm test
```

Сравнить с предыдущей версией кодека на детерминированном наборе:

```bash
node scripts/compare-suite.js 8e18ef0
```

Для проверки реальных файлов или каталогов добавьте их пути после номера коммита. Скрипт проверяет размеры, восстановление байтов и чтение архивов предыдущей версии. Его синтетические коэффициенты не являются результатами закрытой арены.
