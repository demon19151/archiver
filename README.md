# Архиватор

Веб-приложение для сжатия и восстановления файлов без потери данных. Поддерживает одиночную и пакетную обработку, выбор файлов, статистику, скачивание архивов и восстановленных файлов.

## Архитектура

Пользовательский сайт обрабатывает файлы локально в браузере в отдельном Web Worker. Исходные данные не отправляются на сервер, поэтому сайт может работать с большими файлами без ограничения тела запроса Vercel.

Серверный API работает отдельно и используется песочницей преподавателя. Он запускает тот же кодек и принимает один файл одним HTTP-запросом.

## Методы архивирования

- **LZSS + Huffman** — поиск повторяющихся фрагментов и компактное кодирование.
- **RLE** — сжатие серий одинаковых байтов.
- **Repeat** — запись периодически повторяющихся блоков.
- **Delta и byte-shuffle** — преобразования для числовых данных, бинарных записей и PCM-аудио.
- **Store** — безопасное сохранение исходных данных, когда сжатие невыгодно.

Для каждого файла автоматически выбирается самый короткий корректный вариант.

## Структура проекта

- `src/codec.js` — общий кодек сжатия и распаковки.
- `src/server.js` — локальный HTTP-сервер и статические файлы.
- `src/browser/` — браузерная адаптация кодека и Web Worker.
- `public/` — пользовательский интерфейс.
- `api/` — serverless-обработчики для Vercel API.
- `test/` — тесты кодека и браузерного Worker.
- `scripts/` — сборка браузерного Worker и benchmark.
- `vercel.json` — конфигурация Vercel.

## Запуск

Требуется Node.js 18 или новее.

Установить зависимости:

```bash
npm ci
```

Запустить локальный сайт и API:

```bash
npm start
```

Открыть сайт:

```text
http://localhost:3000
```

Собрать браузерный Worker:

```bash
npm run build
```

Запустить тесты:

```bash
npm test
```
