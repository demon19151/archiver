# Архиватор

Архиватор файлов с веб-интерфейсом и поддержкой сжатия и восстановления файлов без потери данных. Можно загружать один или несколько файлов, выбирать файлы для обработки, просматривать статистику и скачивать готовый архив или восстановленные файлы.

На сайте файлы обрабатываются целиком в фоновом потоке браузера, без загрузки на сервер. Сайт и сервер используют один кодек и совместимые архивы. Максимальный исходный файл — 128 МиБ; скорость и доступная память зависят от устройства.

## Методы архивирования

- **LZSS + Huffman** — поиск повторяющихся фрагментов и эффективное кодирование токенов.
- **RLE** — сжатие длинных последовательностей одинаковых байтов.
- **Repeat** — компактная запись периодически повторяющихся блоков.
- **Delta и byte-shuffle** — преобразования для числовых данных, бинарных записей и PCM-аудио.
- **Store** — безопасное сохранение исходных данных, если сжатие не даёт выигрыша.

Для каждого файла автоматически выбирается наиболее компактный вариант.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm ci
npm start
```

Откройте в браузере:

```text
http://localhost:3000
```

Запуск тестов:

```bash
npm test
```
